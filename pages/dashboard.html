Calculation Settings

Admin only. Configure exactly which transactions count toward Total Profit, Net Profit and related cards. Saved globally to settings/system.dashboard.

Income Components

Include Deposit Income
Count profit_income records (registration fees, service fees, etc.) as income.
Include Loan Interest Income
Count interest earned on approved loans as income.
Include Penalty Income
Count paid/done/approved penalties as income.
Deduct Service Withdrawals
Subtract SACCO service withdrawals (education, medical, etc.) from income → Net Profit.

Deposit Income Filters

Exclude "Other" Deposits
Skip deposits with incomeType = "Other" or "Other Deposit". This matches the Deposits & Dividends pages.

Loan Interest Filters

Include only fully Paid Loans
If ON, interest is only counted for loans with status "paid" (realized income). If OFF, active loans are also counted (expected income).
